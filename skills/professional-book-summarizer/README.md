# 专业书籍内容概括助手

一个用于生成中文书籍概述的 Codex Agent Skill。它会先核实书籍版本信息，再以固定结构输出核心主旨、内容简述以及价值与局限，并对小说的关键结局与核心悬念进行保护。

## 使用方式

将 `professional-book-summarizer` 目录放入支持 Agent Skills 的项目技能目录，或保留在本项目的 `skills/` 目录中。

提供书名即可触发该技能，例如：

```text
请概括《百年孤独》。
```

也可以追加输出要求：

```text
请用适合读书分享演讲稿的形式概括《百年孤独》。
```
